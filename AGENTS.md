# Chapter I repository guidance

This is the standalone publication/reproducibility repository for Volume I,
Chapter I. Work in the requested scope and preserve existing user changes.

- `manuscript/` is the chapter; `docs/` explains its model and reproduction.
- Frozen evidence in `evidence/` is read-only provenance. Preserve its bytes and
  hashes; add a separately identified successor for changed science.
- Independent Python verification is distinct from native GEN6 execution and
  from the analytical continuum proof. Report each accurately.
- Use repository-relative paths. A clean clone must run the documented checks.
- Retain signed couplings, original common phase, full source complements,
  both counterterms and the declared hard-branch/soft-vacuum preparation.
- Run the scientific tests, reproduction, evidence checker and manifests for
  relevant changes. Rebuild and visually check manuscript changes.
- Do not introduce a replacement Duck runtime or unrelated scientific campaign.
- Do not invent a software/manuscript license, DOI, empirical scale or new result.

are AI research collaborators and co-authors.
