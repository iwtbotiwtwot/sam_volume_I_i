# Contributing

Sean Brady is the originator and conceptual director. OpenAI ChatGPT and Codex
are AI research collaborators and co-authors.

Original software contributions use MIT; original manuscript, documentation and
research-material contributions use CC BY 4.0. See [the license scope](docs/LICENSING.md).
Keep third-party notices and identify any separately licensed contribution.
Use the authorship wording in [AUTHORS.md](AUTHORS.md), and preserve the
distinction between collaboration credit and copyright ownership.

Keep original rules, receiving assignments, mathematical deductions, native
certification and independent verification identifiable in each change.

1. Install the core package and run `python -m unittest discover -s tests -v`.
2. Run `python scripts/reproduce.py` and the original checker command in the README.
3. Verify both artifact manifests. Never update expected evidence to conceal a
   failing scientific or integrity check. New evidence gets a new source binding.
4. For manuscript edits, rebuild the PDF, check its text/structure, and visually
   inspect every changed page. Preserve the seven-page chapter scope or explain
   an intentional editorial change.
5. Describe the changed behavior, input source, verification and remaining scope.

Historical absolute paths inside frozen evidence are provenance. New code must
resolve bundled files through the checked repository-relative map. Do not add
operator credentials, caches, virtual environments or unrelated research data.

The four signed/current and action distinctions to preserve are: original
gamma_W versus common chi versus clock theta; calibration expectation versus
hard-branch preparation; Delta versus Omega versus actual nu; and local 1/nu
versus the finite-window mean inverse. Both polarization counterterms and the
same underlying actual nu belong in every action comparison.
